# MockMate

MockMate is an AI-powered mock interview platform that helps users practice job interviews and get instant feedback.

## Tech Stack
- **Frontend**: Next.js (App Router), React, Tailwind CSS, shadcn/ui
- **Backend**: Next.js API Routes, NextAuth.js
- **Database**: SQLite (via Prisma)
- **AI**: Anthropic API (Claude 3.5 Sonnet)

## Setup Instructions

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Environment Variables**
   Ensure you have a `.env` file in the root directory. Add your Anthropic API Key and a NextAuth secret:
   ```env
   DATABASE_URL="file:./dev.db"
   ANTHROPIC_API_KEY="your-anthropic-api-key"
   NEXTAUTH_SECRET="any-random-string-for-dev"
   ```

3. **Database Setup**
   The project uses SQLite for local development. Run the following to initialize the database:
   ```bash
   npx prisma db push
   ```

4. **Run the Development Server**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Usage
- **Sign In**: The app uses a dummy credentials provider for the MVP. Simply enter any email and password, and an account will be created automatically.
- **Onboarding**: Select your target role, level, and interview type.
- **Interview**: Answer the questions generated by Claude. Claude will evaluate your answers on the fly and may ask dynamic follow-up questions.
- **Feedback**: Upon completion, you will receive a detailed feedback report scoring your performance and suggesting improvements.
